## Learning methodology

Project-first.

Do not learn technologies only through tutorials.

AI can be used as:
- tutor
- reviewer
- debugger
- interviewer

Do not merge code that cannot be explained.

Each important topic should eventually demonstrate:

1. KNOW IT
2. BUILD IT
3. BREAK/FIX IT
4. DESIGN WITH IT
5. DEFEND IT
6. PASS IT
